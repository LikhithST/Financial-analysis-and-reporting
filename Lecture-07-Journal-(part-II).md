# Lecture 7: Journal (Part II) — Ledger

## 1. Purpose of a Ledger

A **ledger** classifies transactions of a similar type under individual accounts. After transactions are first recorded in the journal, they are posted to the relevant ledger accounts so that the balance of each account can be determined.

## 2. Ledger Format

| Date | Particulars | J.F. | Debit (₹) | Date | Particulars | J.F. | Credit (₹) |
| --- | --- | :---: | ---: | --- | --- | :---: | ---: |
|  | **Dr.** |  |  |  | **Cr.** |  |  |

**J.F. (Journal Folio)** is the page number in the journal where the transaction was originally recorded.

## 3. Rules for Posting to the Ledger

1. An account debited in the journal is posted on that account’s **debit side** in the ledger; an account credited in the journal is posted on that account’s **credit side**. The corresponding account is named in the particulars column.
2. When preparing the Cash Account itself, the words “Cash A/c” are not written in the particulars column; the corresponding account name is used instead.
3. The debit and credit sides of an account are totalled. The difference is entered on the smaller side as **Balance c/d** (balance carried down), so both sides agree.
4. At the start of the next period, the carried-down balance is brought forward on the opposite side as **Balance b/d** (balance brought down).

## 4. Cash Account

Cash is a real account. Cash received is entered on the debit side, and cash paid is entered on the credit side.

| Date | Particulars | J.F. | Debit (₹) | Date | Particulars | J.F. | Credit (₹) |
| --- | --- | :---: | ---: | --- | --- | :---: | ---: |
| Dec. 1, 2011 | To Capital A/c |  | 50,000 | Dec. 3, 2011 | By Purchases A/c |  | 30,000 |
| Dec. 7, 2011 | To Sales A/c |  | 10,000 | Dec. 3, 2011 | By Furniture A/c |  | 5,000 |
| Dec. 22, 2011 | To Naresh Kumar A/c |  | 7,600 | Dec. 25, 2011 | By Vinod Kumar A/c |  | 1,900 |
|  |  |  |  | Dec. 28, 2011 | By Stationery A/c |  | 250 |
|  |  |  |  | Dec. 31, 2011 | By Rent A/c |  | 800 |
|  |  |  |  | Dec. 31, 2011 | By Balance c/d |  | 29,650 |
|  | **Total** |  | **67,600** |  | **Total** |  | **67,600** |

The cash account has a debit balance of ₹29,650. It is shown as **By Balance c/d** on the credit side because the debit total exceeds the credit total. On the first day of the next period, it will appear as **To Balance b/d ₹29,650** on the debit side.

## 5. Capital Account

Capital represents the amount the owner has invested in the business. The owner is treated as separate from the business, so capital is credited when cash is introduced.

| Date | Particulars | J.F. | Debit (₹) | Date | Particulars | J.F. | Credit (₹) |
| --- | --- | :---: | ---: | --- | --- | :---: | ---: |
| Dec. 31, 2011 | To Balance c/d |  | 50,000 | Dec. 1, 2011 | By Cash A/c |  | 50,000 |
|  | **Total** |  | **50,000** |  | **Total** |  | **50,000** |

Capital has a credit balance of ₹50,000. On the first day of the next period, it will be brought down as **By Balance b/d ₹50,000** on the credit side.
