# Lecture 8: Ledger - The Second Book of Accounts

## 1. Continuation from Lecture 7

Lecture 7 introduced the ledger and prepared the **Cash Account** and **Capital Account**. This lecture continues the same posting process for the remaining accounts prepared from the journal entries of Beta India Ltd.

## 2. Ledger Format

| Date | Particulars | J.F. | Debit (Rs.) | Date | Particulars | J.F. | Credit (Rs.) |
| --- | --- | :---: | ---: | --- | --- | :---: | ---: |
|  | **Dr.** |  |  |  | **Cr.** |  |  |

In a ledger account, the debit side is written on the left and the credit side is written on the right. The account named in the journal entry is posted to its own side, and the opposite account is written in the particulars column.

## 3. Purchases Account

Purchases Account records goods bought for resale. Since purchases are an expense, they normally have a debit balance.

| Date | Particulars | J.F. | Debit (Rs.) | Date | Particulars | J.F. | Credit (Rs.) |
| --- | --- | :---: | ---: | --- | --- | :---: | ---: |
| Dec. 3, 2011 | To Cash A/c |  | 30,000 | Dec. 31, 2011 | By Balance c/d |  | 35,000 |
| Dec. 12, 2011 | To Vinod Kumar A/c |  | 5,000 |  |  |  |  |
|  | **Total** |  | **35,000** |  | **Total** |  | **35,000** |

Purchases Account has a **debit balance of Rs. 35,000**.

## 4. Furniture Account

Furniture is an asset. Since furniture comes into the business, Furniture Account is debited.

| Date | Particulars | J.F. | Debit (Rs.) | Date | Particulars | J.F. | Credit (Rs.) |
| --- | --- | :---: | ---: | --- | --- | :---: | ---: |
| Dec. 3, 2011 | To Cash A/c |  | 5,000 | Dec. 31, 2011 | By Balance c/d |  | 5,000 |
|  | **Total** |  | **5,000** |  | **Total** |  | **5,000** |

Furniture Account has a **debit balance of Rs. 5,000**.

## 5. Sales Account

Sales Account records goods sold by the business. Since sales are income, they normally have a credit balance.

| Date | Particulars | J.F. | Debit (Rs.) | Date | Particulars | J.F. | Credit (Rs.) |
| --- | --- | :---: | ---: | --- | --- | :---: | ---: |
| Dec. 31, 2011 | To Balance c/d |  | 24,000 | Dec. 7, 2011 | By Cash A/c |  | 10,000 |
|  |  |  |  | Dec. 9, 2011 | By Naresh Kumar A/c |  | 8,000 |
|  |  |  |  | Dec. 16, 2011 | By Raja A/c |  | 6,000 |
|  | **Total** |  | **24,000** |  | **Total** |  | **24,000** |

Sales Account has a **credit balance of Rs. 24,000**.

## 6. Naresh Kumar Account

Naresh Kumar is a debtor because goods were sold to him on credit. His account is debited when he receives goods and credited when he settles the amount due.

| Date | Particulars | J.F. | Debit (Rs.) | Date | Particulars | J.F. | Credit (Rs.) |
| --- | --- | :---: | ---: | --- | --- | :---: | ---: |
| Dec. 9, 2011 | To Sales A/c |  | 8,000 | Dec. 22, 2011 | By Cash A/c |  | 7,600 |
|  |  |  |  | Dec. 22, 2011 | By Discount Allowed A/c |  | 400 |
|  | **Total** |  | **8,000** |  | **Total** |  | **8,000** |

Naresh Kumar Account is fully settled, so there is **no closing balance**.

## 7. Vinod Kumar Account

Vinod Kumar is a creditor because goods were purchased from him on credit. His account is credited when he supplies goods and debited when payment, discount, or returns reduce the amount payable.

| Date | Particulars | J.F. | Debit (Rs.) | Date | Particulars | J.F. | Credit (Rs.) |
| --- | --- | :---: | ---: | --- | --- | :---: | ---: |
| Dec. 25, 2011 | To Cash A/c |  | 1,900 | Dec. 12, 2011 | By Purchases A/c |  | 5,000 |
| Dec. 25, 2011 | To Discount Received A/c |  | 100 |  |  |  |  |
| Dec. 31, 2011 | To Purchase Returns A/c |  | 500 |  |  |  |  |
| Dec. 31, 2011 | To Balance c/d |  | 2,500 |  |  |  |  |
|  | **Total** |  | **5,000** |  | **Total** |  | **5,000** |

Vinod Kumar Account has a **credit balance of Rs. 2,500**.

|  |  |  |  | Dec. 31, 2011 | By Balance c/d |  | 300 |
|  | **Total** |  | **400** |  | **Total** |  | **400** |

## 14. Key Point

The closing balance is written on the smaller side of the ledger account as **Balance c/d** so that both sides have equal totals. In the next accounting period, this balance is brought down on the opposite side as **Balance b/d**.
